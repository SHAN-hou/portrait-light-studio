# 光感 · 人像布光练习室

针对 SmallRig RC 100B、RC 60B、RC 60C 的中文三维人像布光学习工具。纯静态页面，所有运行依赖与人像模型均保存在此仓库，无需外部 CDN。

在线使用：https://shan-hou.github.io/portrait-light-studio/

电脑、手机均可在浏览器中打开。手机竖屏会把灯光面板放到人物下方；横屏便于比较人像和参数。首次选择写实女模需要下载约 15 MB 模型。设置保存在各设备当前浏览器内，不会自动跨设备同步。

本地运行：在仓库目录执行 `python -m http.server 4175`，再访问 `http://localhost:4175/`。浏览器需支持 WebGL 2。

GitHub Pages 从 `main` 分支根目录发布，`.nojekyll` 用于直接提供静态文件。更新网站文件并推送到 `main` 后会自动重新发布。

功能：三盏灯独立开关、亮度、色温、RC60C 彩色模式、灯位拖动与键盘滑杆、距离与高度、柔光箱近似、四种预设、新手练习、旋转观察、背景与曝光、画面对比及 PNG 导出。灯光设置在当前浏览器本地保存。

模拟限制及设备来源见网站“设备参数与模拟说明”。本工具是相对变化的教学模拟，未经实测标定。默认虚拟柔光箱的输出系数为 0.35，4 个光源样本用于近似面积光与柔和阴影。RGB 模式不提供照度估计。

模型 Infinite, 3D Head Scan by Lee Perry-Smith（triplegangers.com），CC BY 3.0；调整了模型尺寸和材质。完整原始许可位于 assets/head-LICENSE.txt。Three.js 0.170.0 使用 MIT 许可，位于 vendor/LICENSE.txt。


新增写实女模：基于 MakeHuman CC0 资产制作的三维虚拟人物，带肤色纹理、睁眼、头发和黑色衣领。可与原版哑光胸像切换，保留灯光和曝光，选择随本地设置保存。新模型首次选择时加载、随后复用；加载失败时保留原模特并可重试。完整来源与许可：assets/portrait-LICENSE.txt。仍为实时渲染教学近似，未模拟完整皮肤次表面散射或发丝散射。
